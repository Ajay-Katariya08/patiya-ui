Welcome to the documentation site source code for **Patiya UI**. This Next.js application serves as the interactive showcase and installation guide for Patiya UI, a premium **React UI components** library built entirely with **Tailwind CSS**.

## ✨ Live Demo & Documentation

Visit the official site to explore all components:  
**🔗 [patiya-ui.vercel.app](https://patiya-ui.vercel.app)**

## 🚀 Why Patiya UI?

If you are looking for a highly customizable **Tailwind CSS component library**, Patiya UI gives you over 50+ beautiful, fully accessible, copy-paste ready **React UI components** including:

- Advanced Layouts (Dock, Spotlights, Direction-Aware Hover)
- Interactive Elements (Shimmer buttons, Magnetic buttons, Scratch to Reveal)
- Standard Form Elements (Inputs, Selects, Sliders, Switches)
- Data Display (Tables, Carousels, Charts, Timelines)
- Navigation & Overlays (Modals, Drawers, Dropdowns)

It's the perfect toolkit to rapidly build modern, sleek, and highly interactive React applications.

## 💻 Running the Docs Locally

This documentation site is a [Next.js](https://nextjs.org) project bootstrapped with `create-next-app`.

First, install the dependencies:

```bash
bun install
```

Then, run the development server:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can start editing the page by modifying `app/page.tsx`.
